# Clapre

Independent software studio in Seoul. Website: **[clapre-app.github.io](https://clapre.app/)**

## ingtype

Your iPad as a silent Magic Keyboard, your iPhone as the trackpad and air mouse for your Mac.
Korean (Hangul) input that never breaks, ten-finger typing on the desk, no sound, no account, no tracking.

- Website: https://clapre.app/#ingtype
- Support: https://clapre.app/#support
- Privacy: https://clapre.app/#privacy

아이패드를 무소음 매직 키보드로, 아이폰을 Mac 트랙패드·에어 마우스로. 한글이 깨지지 않는 입력.
